This local trial runner compares two equivalent timetable renderings using different class strategies. It reports raw times; it does not decide statistical significance. Record your browser, OS, viewport, and procedure, and rerun under controlled conditions.

Test protocol to document

  1. Record browser/version, OS/device, viewport, power mode, and date.
  2. Use same rows, text, CSS visual values, and local-only assets.
  3. Run one untimed warm-up for each variant, then run five measured trials per variant.
  4. Alternate which variant runs first between paired trials. Do not run other heavy tasks.
  5. Save raw results and calculate medians. If the data varies widely or ranges overlap, describe that uncertainty.

Falsifiable claim: Write your own prediction and threshold in the main document before using the runner. The generated measurements are your data only after you run the test.
