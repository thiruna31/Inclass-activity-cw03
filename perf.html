CSS Performance Experiment

Claim: the utility-class timetable needs at least 5% more time to parse, style and lay out than the component-class timetable (same visual result).

Method: each trial writes 1,500 timetable rows into a fresh hidden iframe, forces layout, and records the elapsed time. Every timed run is preceded by a discarded throwaway run of the same version, and the order alternates A, B, A, B so background load is spread evenly.
